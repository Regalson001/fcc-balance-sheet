# Balance Sheet

A professional financial balance sheet web application built as part of the freeCodeCamp Responsive Web Design curriculum. This project showcases advanced CSS techniques for structuring and styling tabular financial data.

## 🚀 Features

* **Accessibility-First Design:** Implements `.sr-only` utility classes and ARIA attributes (`scope="col"`, `scope="row"`) to ensure screen-reader compatibility.
* **Advanced CSS Styling:** 
  * Dynamic sizing using `calc()` and custom padding configurations.
  * Tabular layout alignment with `border-collapse` and distinct row/cell padding rules.
  * Visual polish using linear gradient row backgrounds and interactive pseudo-class hover states (`:hover`, `:nth-of-type`).
* **Responsive Layout:** Cleanly presents multi-year financial data (2019–2021) with structured asset breakdowns and line-item descriptions.

## 🛠️ Built With

* **HTML5** (Semantic table structuring: `<table>`, `<caption>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`)
* **CSS3** (Selectors, pseudo-classes, Flexbox/Box-model styling, linear gradients)
